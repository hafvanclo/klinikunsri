# Unsri Health Zone (Klinik UNSRI)

**Unsri Health Zone** merupakan aplikasi kesehatan yang dirancang khusus untuk meningkatkan akses layanan klinik di Universitas Sriwijaya. Aplikasi ini memudahkan pengguna untuk memeriksa jadwal dokter, memesan obat, memanggil ambulans dalam keadaan darurat, dan berkomunikasi langsung dengan pihak klinik. Dengan fitur-fitur ini, aplikasi ini membantu mengatasi masalah seperti penundaan pelayanan dan ketidakpastian informasi.

## Fitur

1. **Ambulans**
   - Menerima permintaan panggilan ambulans dari pengguna.
   - Menentukan lokasi pengguna berdasarkan GPS.
   - Memberikan informasi status panggilan kepada pengguna.

2. **Darurat**
   - Fitur yang mempersingkat proses panggilan ambulans dalam keadaan darurat.

3. **Jadwal Dokter**
   - Menampilkan jadwal praktek dokter.
   - Memungkinkan pencarian jadwal berdasarkan tanggal dan spesialisasi.

4. **Obat**
   - Mengkategorikan layanan obat.
   - Menampilkan daftar obat yang tersedia berdasarkan kategori.
   - Menghitung total biaya pembelian.
   - Menyediakan metode pembayaran yang aman.
   - Memberikan informasi status pemesanan obat.

5. **Customer Service**
   - Layanan chat atau panggilan suara dengan petugas customer service.
   - Memberikan informasi terkait layanan klinik.
   - Menerima laporan atau keluhan dari pengguna.

## Instalasi

Langkah-langkah untuk menginstal dan menjalankan proyek ini di lingkungan lokal:

```bash
# Clone repository ini
git clone https://github.com/hafvanclo/klinikunsri

# Masuk ke direktori proyek
cd klinikunsri

# Install dependencies
npm install

# Jalankan aplikasi
npm start
